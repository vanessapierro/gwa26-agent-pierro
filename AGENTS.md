# Projekt

Dieser Ordner gehört zum Agenten für [Name des Unternehmens]. Der Agent erledigt diese Aufgabe: [konkrete Aufgabe, zum Beispiel drei Instagram-Beiträge pro Woche zur Online-Terminbuchung]. Später wird der Agent mit Google ADK als Web-App gebaut.

Im Ordner kontext liegen die Angaben zum Unternehmen, je Thema eine Datei: unternehmen.md, zielgruppe.md, positionierung.md, aarrr-stufe.md, marke.md und ziele.md.

# Regeln

- Antworte auf Deutsch.
- Verwende nur Fakten aus den Dateien im Ordner kontext. Schreibe „Annahme:“ vor jede Angabe, die nicht aus diesen Dateien stammt.
- Halte dich an den Ton aus kontext/marke.md.
- Lege Ergebnisse als neue Datei im Ordner ergebnisse an. Ändere bestehende Dateien nur, wenn ich es ausdrücklich verlange.
- Beträge in EUR mit Komma, zum Beispiel 27,00 EUR.
